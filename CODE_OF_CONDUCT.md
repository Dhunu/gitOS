# Code of Conduct

GitOS follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, disagree about ideas rather than people, and accept feedback gracefully. Harassment, personal attacks and sharing someone's private information aren't acceptable.

## Reporting

If you see or experience unacceptable behavior, please contact the maintainer privately using the public email on [@Dhunu's GitHub profile](https://github.com/Dhunu). Reports are handled in confidence.

Maintainers may remove comments or code, or block people from the project, when these standards aren't met.
